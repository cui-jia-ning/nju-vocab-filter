# 南大通用英语词汇 · 阅读与筛选工具

南京大学《大学英语通用词汇》表的网页版阅读与单词筛选工具。纯前端单页应用，数据全部内嵌，无需联网、无需后端。

**🔗 在线使用（点开即用，可转发分享）：https://cui-jia-ning.github.io/nju-vocab-filter/**

## 功能

**📖 词表阅读**
- 完整收录 **3,086 个词条**（A 级 570 / B 级 1,217 / C 级 1,299），与官方词表数量一致
- 按级别（A/B/C 级彩色徽标）、首字母筛选
- 搜索单词或中文释义
- 释义遮罩自测模式（释义模糊，点击显形）
- 音标内嵌显示，点击单词或 🔊 即可语音朗读（浏览器 TTS，离线可用）
- 每个词条配有英文例句与中文翻译，点「例句 ▸」展开，可朗读整句
- 分页浏览，一键导出当前筛选结果

**✅ 单词筛选 → 个人词库**
- 单击「+ 加入词库」，或开启批量筛选模式勾选整页一键加入
- 已入库单词自动去重并标记，可切换「隐藏已入词库」专注生词
- 词库保存在浏览器 localStorage，不上传任何数据

**⭐ 个人词库**
- 库内搜索、单个移除、清空
- 导出 TXT / JSON，支持导入 JSON 跨设备迁移

## 使用

方式一（最简单）：直接双击打开 `index.html`。

方式二（本地服务器）：

```bash
npm run dev          # 默认 http://127.0.0.1:7100/
npm run dev -- --port 3000
```

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 应用本体（数据已内嵌，可离线使用） |
| `app_template.html` | 页面模板，词库数据占位注入后生成 `index.html` |
| `vocab.json` | 解析出的结构化词库（3,086 条，含音标与例句） |
| `examples.jsonl` | 3,086 条例句与中文翻译（逐词对应，已并入 vocab.json） |
| `vocab_text.txt` | 从 .doc 提取的全文纯文本 |
| `server.js` | 零依赖静态预览服务器（`npm run dev`） |
| `verify.js` | Edge 无头浏览器 CDP 自动化测试脚本（28 项检查） |

> 原始词表文档（`南京大学大学英语通用词汇.doc`）为二进制格式，未随仓库分发；`vocab.json` 与 `vocab_text.txt` 即为其完整解析结果。

## 数据说明

词表基于四六级考委会词表，删除中小学词汇与派生词后分级：A 级为四级高频词、学术词；B 级为四级次高频词；C 级为六级词（暂不作要求）。从 `.doc` 二进制中提取后经专门解析器清洗（处理全角括号、控制字符、词义内嵌英文、跨级别重复词等），词条数与文档标注完全核对一致。
